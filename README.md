# bq-rincon

Static informational website for a portable toilet company, built with Astro.

See the [project documentation](docs/en/index.md) for the product scope and technical architecture.

## Requirements

- Node.js 24.10.0
- pnpm 11.20.0 through Corepack

## Development

```sh
corepack pnpm install
corepack pnpm dev
```

Run the complete local quality gate with:

```sh
corepack pnpm verify
```
